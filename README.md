# 🎡 Neon Random Spin Wheel (วงล้อสุ่มอาหาร/จับรางวัล)

เว็บแอปพลิเคชันสำหรับสุ่มรายชื่อหรือเมนูอาหาร มาในธีม **Neon Cyberpunk** สุดล้ำ พร้อมระบบเสียงและเอฟเฟกต์พลุกระดาษ (Confetti) พัฒนาด้วย HTML, CSS และ JavaScript โดยไม่ต้องใช้ Framework หนักๆ

## ✨ ฟีเจอร์เด่น (Features)

* **🎨 Modern Neon UI:** ดีไซน์ทันสมัย โทนสีมืดตัดแสงนีออน สบายตาและน่าใช้งาน
* **🎯 Accurate Center Text:** ระบบจัดวางตัวอักษรให้อยู่กึ่งกลางช่องเป๊ะๆ อ่านง่าย ไม่ทับกันแม้รายชื่อจะเยอะ
* **🔊 Real-time Sound Effects:**
    * เสียง "ติ๊ก" (Tick) เมื่อวงล้อหมุนผ่านช่อง (สร้างด้วย Web Audio API ไม่ต้องโหลดไฟล์ mp3)
    * เสียง "ชนะ" (Win) เมื่อได้ผู้โชคดี
* **🎊 Celebration Effect:** เอฟเฟกต์พลุกระดาษระเบิดเมื่อสุ่มเสร็จ
* **📝 Bulk Import:** รองรับการเพิ่มรายชื่อทีละเยอะๆ (Copy จาก Excel หรือ Note มาวางได้เลย)
* **📱 Responsive:** ใช้งานได้ดีทั้งบนคอมพิวเตอร์และมือถือ

## 🚀 วิธีใช้งาน (How to Use)

1.  **เพิ่มรายชื่อ:**
    * พิมพ์ชื่อในช่องแล้วกด Enter หรือคลิกปุ่ม "เพิ่ม"
    * หรือใช้ช่อง **นำเข้าแบบกลุ่ม** เพื่อก๊อปปี้รายชื่อมาวางทีเดียว (คั่นด้วย `,` หรือขึ้นบรรทัดใหม่)
2.  **เริ่มสุ่ม:** กดปุ่ม **SPIN** ตรงกลางวงล้อ
3.  **ลุ้นผล:** วงล้อจะหมุนพร้อมเสียงประกอบ และหยุดที่ผู้โชคดีพร้อมเอฟเฟกต์ฉลอง
4.  **ลบรายชื่อ:** สามารถกดกากบาท `✕` หลังรายชื่อเพื่อลบ หรือกด "ล้างเมนูทั้งหมด"

## 🛠 การติดตั้งและรันโปรเจกต์ (Installation)

โปรเจกต์นี้เป็น **Static Web** สามารถรันได้ทันทีโดยไม่ต้องลงโปรแกรมเพิ่ม

1.  **Clone** หรือ **Download** ไฟล์ทั้งหมดลงเครื่อง
2.  ดับเบิ้ลคลิกไฟล์ `index.html` เพื่อเปิดผ่าน Browser (แนะนำ Chrome, Edge, หรือ Firefox)

## ⚙️ การแก้ไขข้อมูลเริ่มต้น (Configuration)

หากต้องการเปลี่ยน **เมนูอาหารเริ่มต้น** หรือรายชื่อ Default สามารถแก้ได้ที่ไฟล์ `index.html`

1.  เปิดไฟล์ `index.html` ด้วย Text Editor (เช่น VS Code, Notepad++)
2.  เลื่อนลงมาด้านล่างสุดในส่วน `<script>`
3.  ค้นหาตัวแปร `prizes` และแก้ไขข้อมูลในวงเล็บ `[ ... ]`

```javascript
// ตัวอย่างการแก้ไข
let prizes = [
    "ข้าวมันไก่", 
    "กะเพราหมูสับ", 
    "ชาบู", 
    // เพิ่มเมนูของคุณที่นี่...
];
```
